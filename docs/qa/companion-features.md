## Limits

Stock pinned ES exposes formatted system timecodes, not raw system seconds, and its actual expression parser lacks the required generic string operations. This implementation uses saved full-gamelist totals: hidden/stale records may be included; native visible filters and unsaved time are not mirrored. Reload the theme after refreshing. Unsupported collections remain unavailable. Per-file atomic publication is not a multi-file transaction: interruption can leave owned outputs requiring review. Source gamelists, display timings, original theme defaults and unrelated dirty-tree work are not changed by setup.
