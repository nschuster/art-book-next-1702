# Achievement companion palette previews

Actual SDL dummy-driver captures with synthetic progress data, not native
EmulationStation screenshots or physical Batocera/CRT validation.

- [Palettes 1](palettes-1.png): Default, Light, SteamOS, SNES.
- [Palettes 2](palettes-2.png): Famicom, OLED, C64, Custom (shipped template).
- [C64 setup](setup-c64.png): actual extracted Ports bootstrap against a local fixture.
- Individual frames are 640×480 and independently captured 320×240.
- `manifest.json` paths are relative to this directory.

The native menu's gold/blue progress is not recoloured. See
[QA and limitations](../../docs/qa/ra-sync-palettes.md).
